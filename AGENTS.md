# AGENTS.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What this is

A personal Hyprland config written in the **Lua config format** (Hyprland 0.55+), integrated with DankMaterialShell (DMS). There is no build or test suite. The repo is symlinked to `~/.config/hypr` by `./install.sh`, so edits here take effect on the live desktop.

## Commands

- Install: `./install.sh` symlinks the repo to `$XDG_CONFIG_HOME/hypr` and backs up any existing dir as `hypr.backup.*` (gitignored).
- Apply changes: `hyprctl reload`. Then check `hyprctl configerrors` for Lua/config errors.
- Submodule: `git submodule update --init` (fetches `plugins/split-monitor-workspaces`).
- Editor/LSP: `.luarc.json` points lua-language-server at `/usr/share/hypr/stubs` and declares `hl` as a global. `hl.meta.lua` is an autogenerated copy of the API stubs; don't edit it, but use it to look up `hl.*` signatures, event names and dispatchers.

## Architecture

`hyprland.lua` is the entry point. It adds `./?.lua;./?/init.lua` to `package.path` so modules resolve relative to the config dir, sets base options/window rules, then `require`s modules **in order**. Later `hl.config` calls override earlier ones key by key, so load order matters:

1. `hyprland.lua` base settings
2. `dms/*.lua` (colors, outputs, layout, cursor, input, binds, binds-user, windowrules)
3. `umbe-layout.lua` → `umbe-binds.lua` → `umbe-split-workspace.lua` (personal overrides, loaded last)

### DMS-owned files: be careful

- Most of `dms/*.lua` is **generated by DMS** ("Auto-generated by DMS — do not edit manually"). `dms setup` overwrites `dms/binds.lua` with the stock set and saves changed copies to `.dms-backups/`.
- `dms/binds-user.lua` is never touched by `dms setup`, but the DMS keybind editor rewrites it and keeps only `hl.bind`/`hl.unbind` lines.
- The `-- DMS_STARTUP_BEGIN/END` block in `hyprland.lua` is managed by DMS.
- Put personal customizations in the `umbe-*.lua` files, not in `dms/`.

### Personal modules

- `umbe-layout.lua`: sets the default layout to Hyprland's native `monocle` with no gaps/borders. This overrides DMS's `scrolling`.
- `umbe-binds.lua`: the `bind_key` helper unbinds before binding, so it can override DMS binds. `per_layout({ [layout] = dispatcher, default = ... })` chooses a dispatcher based on the active workspace's `tiled_layout`. `default` is skipped in monocle. `SUPER+SHIFT+M` toggles monocle ↔ scrolling and emits a `hyprlayout,<name>` event so the DMS layout widget updates.
- `umbe-split-workspace.lua`: configures the `split-monitor-workspaces` Lua package (per-monitor workspaces 1–10, `SUPER+N` / `SUPER+SHIFT+N`, `SUPER+SHIFT+G` grabs rogue windows).

### Plugin submodule

`plugins/split-monitor-workspaces` is a git submodule (zjeffer/split-monitor-workspaces). It's used as a **pure Lua package** via `require("plugins.split-monitor-workspaces")` (`init.lua` → `lua/split-monitor-workspaces.lua`), not as the C++ `.so` plugin. Its checkout must match the installed Hyprland release branch (`release/0.XX.x`).

**Never modify submodules** (anything under `plugins/`): don't edit their files, commit inside them, check out other refs, or bump the submodule pointer. If a fix seems to need a submodule change, work around it in this repo's own files (e.g. `umbe-split-workspace.lua`) or tell the user instead.

### Other files

- `hyprlock.conf` / `hypridle.conf` use the classic hyprlang format. `hyprlock.conf` sources `~/.config/hypr/mocha.conf` (Catppuccin Mocha palette).
- `colors.lua` / `colors.conf` are color palettes. `dms/colors.lua` is the one DMS generates.
